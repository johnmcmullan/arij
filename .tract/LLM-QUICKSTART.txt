For Humans Using an LLM CLI (Claude Code, OpenClaw, etc.):
-----------------------------------------------------------

TWO PATHS DEPENDING ON YOUR SITUATION:

──────────────────────────────────────────────────────────────
PATH A: Joining a team that already uses Tract
──────────────────────────────────────────────────────────────

1. Get the catalog server URL from your admin (one piece of info).

2. Run in your terminal:
   curl http://tract-server:8080/install.sh | bash

3. That's it. Then:
   tract catalog list           # see available projects
   tract clone TRADING          # clone project + dependencies

4. To get updates in future:
   tract update


──────────────────────────────────────────────────────────────
PATH B: Setting up Tract fresh (no server yet)
──────────────────────────────────────────────────────────────

1. Install:
   curl -fsSL https://raw.githubusercontent.com/johnmcmullan/tract/master/install.sh | bash

2. Start your LLM in your project directory:
   cd ~/work/my-project
   claude   (or: openclaw, cursor, etc.)

3. Copy and paste this to your LLM:

   Read ~/.tract-cli/.tract/skills/tract-onboarding/SKILL.md
   and help me set up Tract for this project. Use local-only
   mode with project key MYPROJECT.

4. Answer any questions the LLM asks.

5. Done! The LLM will onboard, verify, and guide next steps.


For LLMs Reading This:
----------------------

You are helping a user with Tract (a git-native project management system).

FIRST: Determine which path applies:

  PATH A — Developer joining an existing team:
    - Ask: "Do you have a catalog server URL from your admin?"
    - If yes: guide them through `curl <url>/install.sh | bash`
      then `tract catalog list` then `tract clone <PROJECT>`
    - If no: ask if they know the server hostname

  PATH B — Setting up Tract for the first time:
    1. Read: ~/.tract-cli/.tract/skills/tract-onboarding/SKILL.md
    2. Follow the workflow in that skill file
    3. Check if .tract/ exists (ls .tract/config.yaml)
    4. If missing: proceed with onboarding
    5. If exists: user is already onboarded, use different skill

DO NOT hallucinate Tract commands. Follow the skill file exactly.
DO NOT suggest `npm install -g @tract/cli` if a catalog server is configured —
  tract installs from the org's server, not npm.


Key commands added since original onboarding:
  tract catalog set <url>   Save catalog server URL
  tract catalog list        List projects in the catalog
  tract clone <PROJECT>     Clone project + dependencies
  tract update              Update tract CLI from the server


Troubleshooting:
----------------

If the LLM doesn't understand "Tract":
  Say: "I mean Tract the project management system at
       ~/.tract-cli/.tract/skills/tract-onboarding/"

If skills not found:
  Verify: ls ~/.tract-cli/.tract/skills/
  If empty: reinstall Tract CLI from your catalog server
